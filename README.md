# מודל CNN לזיהוי צורות – תרגיל 2

רשת נירונים קונבולוציונית (Convolutional Neural Network) הממומשת **מאפס** בצד הלקוח של הדפדפן, ב-JavaScript נקי בלבד — **ללא שום ספרייה חיצונית**. המודל מזהה שלוש צורות שמציירים ביד על Canvas: **עיגול, ריבוע ומשולש**.

## הדפים

הפרויקט בנוי משני דפי HTML, עם קבצי CSS ו-JavaScript נפרדים:

- **`index.html`** – דף הבית, ובו מילון מקיף של 45 מושגים בעולם ה-AI וה-CNN.
- **`model.html`** – עורך הציור ומסך ניהול ואימון המודל.

## הרצה

אין צורך בשרת או בהתקנות. אפשר להריץ בשתי דרכים:

1. **מקומית** – לפתוח את `index.html` (או `model.html`) ישירות בדפדפן.
2. **GitHub Pages** – דרך הקישור שמופק בהגדרות ה-repo.

המודל המאומן נטען אוטומטית מקובץ המשקלים `pretrained.js`, כך שמיד עם פתיחת הדף יש מודל מאומן ומוכן לבדיקה.

## מבנה הקבצים

## ארכיטקטורת המודל

```
Input 14x14  →  Convolution  →  ReLU  →  Max Pooling 2x2  →  Flatten  →  Dense  →  Softmax(3)
```

- **Convolution** – פילטרים נלמדים הסורקים את התמונה ומחלצים מאפיינים.
- **ReLU** – פונקציית הפעלה: `f(x) = max(0, x)`.
- **Max Pooling 2x2** – צמצום ממדי מפת המאפיינים (stride 2).
- **Flatten + Dense** – שיטוח לווקטור ושכבות מלאות.
- **Softmax** – הפיכת הפלט להתפלגות הסתברויות בין 3 הצורות.
- **Backpropagation + Gradient Descent** – אלגוריתם האימון שמעדכן את כל המשקלים, כולל הפילטרים.

## שליטה במודל

בדף המודל ניתן לקבוע, לפני האימון:

- מספר שכבות מלאות (Hidden Layers)
- מספר נירונים בכל שכבה (Neurons)
- מספר פילטרים (Filters)
- גודל פילטר (Filter Size)
- קצב למידה (Learning Rate)
- מספר מחזורי אימון (Epochs)

לחיצה על **"קבע פרמטרים ואתחל רשת"** נועלת את הפרמטרים ויוצרת רשת חדשה. מכאן ואילך הם מקובעים עד אתחול.

## אופן השימוש

1. לקבוע פרמטרים וללחוץ **"קבע פרמטרים ואתחל רשת"**.
2. לצייר צורה במרכז הלוח.
3. לבחור תגית ולהוסיף לסט האימון (אופציונלי – קיים גם סט אימון אוטומטי).
4. ללחוץ **"אמן מודל (Train)"** – המודל לומד ומשתפר, וה-Loss וה-Accuracy מתעדכנים.
5. לצייר צורה חדשה וללחוץ **"בדיקה (Predict)"** לקבלת הזיהוי, ההסתברויות ותצוגת מפות המאפיינים.
6. **"אתחול (Reset)"** מאפס את המודל ואת המשקלים השמורים.

## שמירת משקלים
