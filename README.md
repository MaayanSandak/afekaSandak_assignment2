# מודל CNN לזיהוי צורות – תרגיל 2

רשת נירונים קונבולוציונית (Convolutional Neural Network) הממומשת **מאפס** בצד הלקוח של הדפדפן, ב-JavaScript נקי בלבד — **ללא שום ספרייה חיצונית**. המודל מזהה שלוש צורות שמציירים ביד על Canvas: **עיגול, ריבוע ומשולש**.

## הדפים

הפרויקט בנוי משני דפי HTML, עם קבצי CSS ו-JavaScript נפרדים:

- **`index.html`** – דף הבית, ובו מילון מקיף של 45 מושגים בעולם ה-AI וה-CNN.
- **`model.html`** – עורך הציור ומסך ניהול ואימון המודל.
