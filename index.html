ברוכים הבאים לפרויקט ה-CNN שלי

בפרויקט זה מימשנו רשת נירונים קונבולוציונית (Convolutional Neural Network) מלאה בצד הלקוח, תוך שימוש ב-JavaScript נקי בלבד וללא ספריות חיצוניות.

מילון מושגים מקיף בעולם ה-AI וה-CNN (לפחות 40 מושגים)

להלן המונחים המרכזיים המלווים את הארכיטקטורה, הקוד ותהליך האימון של המערכת:

1. AI (Artificial Intelligence): בינה מלאכותית - תחום במדעי המחשב העוסק ביצירת מערכות הפועלות ולומדות בצורה אוטונומית.
2. Machine Learning: למידת מכונה - תת-תחום ב-AI המאפשר למחשבים ללמוד מתוך נתונים ללא תכנות מפורש.
3. Deep Learning: למידה עמוקה - טכנולוגיה המשתמשת ברשתות נירונים מרובות שכבות לזיהוי תבניות מורכבות.
4. CNN (Convolutional Neural Network): רשת נירונים קונבולוציונית - ארכיטקטורת רשת המותאמת במיוחד לעיבוד וזיהוי תמונות.
5. Biological Neuron: נירון ביולוגי - תא עצב במוח האנושי המעבד ומעביר אותות חשמליים, המהווה השראה לרשתות מלאכותיות.
6. Artificial Neuron: נירון מלאכותי - יחידת חישוב בסיסית ברשת המקבלת קלטים, מכפילה אותם במשקלים ומחזירה פלט.
7. Input Layer: שכבת הקלט - השכבה הראשונה ברשת המקבלת את הנתונים הגולמיים (למשל, הפיקסלים מה-Canvas).
8. Hidden Layer: שכבה חבויה - שכבת חישוב שנמצאת בין שכבת הקלט לשכבת הפלט ומחלצת מאפיינים מהמידע.
9. Output Layer: שכבת הפלט - השכבה האחרונה שמציגה את תוצאת המודל (זיהוי אחת מ-3 הצורות).
10. Convolution: קונבולוציה (קיפול) - פעולה מתמטית הסורקת את התמונה בעזרת מטריצה קטנה ומחלצת מאפיינים מרחביים.
11. Filter / Kernel: מסנן / גרעין - מטריצה קטנה של משקלים המשמשת לסריקת התמונה ואיתור קווים, קצוות וצורות.
12. Feature Map: מפת מאפיינים - המטריצה המתקנת לאחר ביצוע פעולת הקונבולוציה, המציגה היכן זוהה המאפיין בתמונה.
13. Stride: פסיעה - מספר הפיקסלים שהפילטר זז בכל שלב בזמן סריקת התמונה.
14. Padding: ריפוד - הוספת שוליים (בדרך כלל אפסים) מסביב לתמונת הקלט כדי לשמור על ממדי המטריצה המקורית.
15. Pooling: צמצום / איחוד - שכבה המקטינה את הממדים הפיזיים של מפת המאפיינים כדי להפחית חישובים ולמנוע Overfitting.
16. Max Pooling: צמצום מקסימלי - שיטת Pooling הלוקחת את הערך המקסימלי מתוך תת-אזור מוגדר במטריצה.
17. Average Pooling: צמצום ממוצע - שיטת Pooling המחשבת את הממוצע של כל הערכים בתת-אזור המוגדר במטריצה.
18. Activation Function: פונקציית אקטיבציה (הפעלה) - פונקציה מתמטית הקובעת האם הנירון יופעל ומה יהיה עוצמת הפלט שלו.
19. ReLU (Rectified Linear Unit): פונקציית הפעלה מתמטית המחזירה 0 עבור ערכים שליליים ואת הערך עצמו עבור חיוביים (f(x)=max(0,x)).
20. Sigmoid: פונקציית אקטיבציה הממירה כל ערך מספרי לטווח שבין 0 ל-1, ומשמשת לחישוב הסתברויות.
21. Weights: משקלים - הפרמטרים המשתנים ברשת המכפילים את ערכי הקלט ומגדירים את עוצמת הקשר בין הנירונים.
22. Bias: היסט - קבוע מתמטי המתווסף לסכום המכפלות של הקלטים והמשקלים כדי להזיז את פונקציית ההפעלה.
23. Weighted Sum: סכום משוקלל - תוצאת החישוב של חיבור כל הקלטים המוכפלים במשקלים שלהם בתוספת ה-Bias.
24. Forward Pass: מעבר קדימה - תהליך הזרמת המידע מהקלט, דרך השכבות השונות, ועד לקבלת הניבוי הסופי בפלט.
25. Backpropagation: הפצה לאחור - אלגוריתם המרכזי לאימון רשתות, המחשב את השגיאה מהסוף להתחלה ומעדכן את המשקלים.
26. Loss / Cost Function: פונקציית הפסד - מדד מתמטי המחשב את גודל הטעות בין ניבוי המודל לבין התשובה הנכונה בפועל.
27. Gradient Descent: שיפוע מורד - אלגוריתם אופטימיזציה המשמש למציאת המשקלים שיביאו למינימום בפונקציית ההפסד.
28. Learning Rate: קצב למידה - גודל הצעד שהאלגוריתם מבצע בכל עדכון של המשקלים במטרה להגיע לטעות מינימלית.
29. Epoch: מחזור למידה - הרצה אחת מלאה של כל נתוני האימון קדימה ואחורה דרך הרשת.
30. Batch / Mini-batch: קבוצת נתונים - תת-קבוצה מתוך מאגר נתוני האימון המוזנת לרשת יחד לפני עדכון המשקלים.
31. Accuracy: דיוק - אחוז המקרים שבהם המודל צדק בניבוי שלו מתוך סך כל הבדיקות שבוצעו.
32. Overfitting: התאמת יתר - מצב שבו המודל לומד את נתוני האימון "בעל פה" אך נכשל בזיהוי נתונים חדשים.
33. Underfitting: התאמת חסר - מצב שבו המודל פשוט מדי ולא מצליח ללמוד את התבניות אפילו על נתוני האימון.
34. Flattening: שיטוח - תהליך המרת מטריצה דו-מימדית (כמו תמונה) לווקטור חד-מימדי ארוך לפני הכניסה לשכבה המלאה.
35. Dense / Fully Connected Layer: שכבה מלאה - שכבה שבה כל נירון מחובר לכל הנירונים בשכבה שלפניה ושכבה שאחריה.
36. LocalStorage: אחסון מקומי - רכיב בדפדפן המאפשר לנו לשמור את משקלי המודל המאומן כמחרוזת טקסט ללא פג תוקף.
37. JSON.stringify(): פונקציית JavaScript הממירה אובייקט או מערך של משקלים למחרוזת טקסט לצורך שמירה ב-LocalStorage.
38. JSON.parse(): פונקציית JavaScript הממירה מחרוזת טקסט מה-LocalStorage חזרה לאובייקט מערכים של משקלים לשימוש הרשת.
39. Training Dataset: מאגר אימון - קבוצת הצורות או התמונות המשמשת את המודל בשלב הלמידה ועדכון המשקלים.
40. Testing Dataset: מאגר בדיקה - קבוצת נתונים חדשה שהמודל לא ראה מעולם, המשמש להערכת רמת הדיוק הסופית שלו.
