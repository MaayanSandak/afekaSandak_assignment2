ברוכים הבאים לפרויקט ה-CNN שלי

בפרויקט זה מימשנו רשת נירונים קונבולוציונית (Convolutional Neural Network) אמיתית בצד הלקוח, ב-JavaScript נקי בלבד וללא ספריות חיצוניות. המודל כולל שכבת קונבולוציה (Convolution) עם פילטרים נלמדים, פונקציית הפעלה ReLU, שכבת איחוד (Max Pooling), שיטוח (Flatten), שכבה/שכבות מלאות, ופלט Softmax. האימון מתבצע באמצעות הפצה לאחור (Backpropagation) עם Gradient Descent.

המודל מזהה שלוש צורות: עיגול, ריבוע ומשולש. ניתן לשלוט במספר השכבות, מספר הנירונים, מספר הפילטרים, גודל הפילטר, קצב הלמידה ומספר ה-Epochs. המשקלים נשמרים ב-LocalStorage ומגובים ב-GitHub (קובץ pretrained.js), כך שהמודל נטען מאומן.

מילון מושגים מקיף בעולם ה-AI וה-CNN (45 מושגים)

להלן המונחים המרכזיים המלווים את הארכיטקטורה, הקוד ותהליך האימון של המערכת. רוב המונחים מופיעים בפועל בקוד (script.js):

1. AI (Artificial Intelligence): בינה מלאכותית - תחום במדעי המחשב העוסק ביצירת מערכות הפועלות ולומדות בצורה אוטונומית.
2. Machine Learning: למידת מכונה - תת-תחום ב-AI המאפשר למחשבים ללמוד מתוך נתונים ללא תכנות מפורש.
3. Deep Learning: למידה עמוקה - טכנולוגיה המשתמשת ברשתות נירונים מרובות שכבות לזיהוי תבניות מורכבות.
4. CNN (Convolutional Neural Network): רשת נירונים קונבולוציונית - ארכיטקטורת רשת המותאמת במיוחד לעיבוד וזיהוי תמונות.
5. Supervised Learning: למידה מונחית - אימון על נתונים מתויגים (תמונה + התווית הנכונה), בדיוק כמו במודל שלנו.
6. Artificial Neuron: נירון מלאכותי - יחידת חישוב המקבלת קלטים, מכפילה אותם במשקלים, מוסיפה Bias ומחזירה פלט.
7. Input Layer: שכבת הקלט - השכבה הראשונה ברשת המקבלת את הנתונים הגולמיים (מטריצת 14x14 פיקסלים מה-Canvas).
8. Hidden Layer: שכבה חבויה - שכבת חישוב בין הקלט לפלט המחלצת מאפיינים. מספרן נשלט מהממשק.
9. Output Layer: שכבת הפלט - השכבה האחרונה (3 נירונים) המציגה את הסתברות כל אחת מ-3 הצורות.
10. Convolution: קונבולוציה - פעולה הסורקת את התמונה בעזרת פילטר קטן ומחלצת מאפיינים מרחביים. מיושמת בקוד בפונקציית ה-forward.
11. Filter / Kernel: מסנן / גרעין - מטריצת משקלים נלמדת (לדוגמה 3x3) המשמשת לסריקת התמונה ואיתור קצוות וצורות.
12. Feature Map: מפת מאפיינים - הפלט של פעולת הקונבולוציה לכל פילטר, מוצג חזותית בדף המודל לאחר הבדיקה.
13. Stride: פסיעה - מספר הפיקסלים שהפילטר/חלון ה-Pooling זז בכל צעד (בקוד שלנו ה-Pooling פוסע ב-2).
14. Padding: ריפוד - הוספת שוליים סביב התמונה כדי לשלוט בממדי הפלט. אנו משתמשים ב-Valid (ללא ריפוד).
15. Pooling: איחוד / צמצום - שכבה המקטינה את ממדי מפת המאפיינים, מפחיתה חישובים ומפחיתה Overfitting.
16. Max Pooling: איחוד מקסימלי - שיטת Pooling הלוקחת את הערך המקסימלי מתוך כל חלון 2x2. מיושמת בקוד.
17. Average Pooling: איחוד ממוצע - שיטת Pooling חלופית המחשבת את הממוצע של חלון הערכים.
18. Activation Function: פונקציית הפעלה - פונקציה לא-לינארית הקובעת את עוצמת פלט הנירון.
19. ReLU (Rectified Linear Unit): פונקציית הפעלה: f(x)=max(0,x). מוחזרים 0 לערכים שליליים והערך עצמו לחיוביים. מיושמת בקוד.
20. Sigmoid: פונקציית אקטיבציה הממירה ערך לטווח 0 עד 1, שימשה ברשתות קלאסיות לחישוב הסתברות.
21. Softmax: פונקציה הממירה את ציוני שכבת הפלט להתפלגות הסתברויות (סכום 1). מיושמת בקוד בשכבה האחרונה.
22. Weights: משקלים - הפרמטרים הנלמדים המכפילים את הקלטים. נשמרים ב-LocalStorage ומגובים ב-GitHub.
23. Bias: היסט - קבוע המתווסף לסכום המשוקלל ומזיז את פונקציית ההפעלה. קיים לכל פילטר ולכל נירון.
24. Weighted Sum: סכום משוקלל - תוצאת W·x + Bias, החישוב הבסיסי של כל נירון.
25. Forward Pass: מעבר קדימה - הזרמת התמונה דרך קונבולוציה, ReLU, Pooling, Flatten והשכבות המלאות עד לניבוי.
26. Backpropagation: הפצה לאחור - אלגוריתם האימון המחשב את השגיאה מהפלט להתחלה ומעדכן את כל המשקלים. מיושם בקוד.
27. Loss / Cost Function: פונקציית הפסד - מדד גודל הטעות. אנו משתמשים ב-Cross-Entropy יחד עם Softmax.
28. Cross-Entropy: אנטרופיה צולבת - פונקציית ההפסד לסיווג רב-מחלקתי, -log של ההסתברות שניתנה למחלקה הנכונה.
29. Gradient Descent: שיפוע מורד - אלגוריתם אופטימיזציה שמעדכן משקלים בכיוון ההפוך לגרדיאנט כדי למזער את ההפסד.
30. SGD (Stochastic Gradient Descent): ירידת גרדיאנט סטוכסטית - עדכון המשקלים אחרי כל דוגמה (כפי שמיושם בלולאת האימון).
31. Learning Rate: קצב למידה - גודל הצעד בכל עדכון משקלים. נשלט מהממשק.
32. Epoch: מחזור למידה - מעבר מלא אחד על כל נתוני האימון קדימה ואחורה. מספרם נשלט מהממשק.
33. Batch / Mini-batch: קבוצת נתונים - תת-קבוצה מהמאגר המוזנת לרשת לפני עדכון. כאן עובדים ב-Batch בגודל 1 (SGD).
34. Accuracy: דיוק - אחוז הניבויים הנכונים מתוך כל הבדיקות. מחושב בקוד באמת מול סט הנתונים.
35. Overfitting: התאמת יתר - המודל לומד את האימון "בעל פה" ונכשל על נתונים חדשים.
36. Underfitting: התאמת חסר - המודל פשוט מדי ולא לומד את התבניות אפילו על נתוני האימון.
37. Flatten: שיטוח - הפיכת מפות המאפיינים הדו-ממדיות לווקטור חד-ממדי לפני השכבה המלאה. מיושם בקוד.
38. Dense / Fully Connected: שכבה מלאה - שכבה שבה כל נירון מחובר לכל נירוני השכבה הקודמת.
39. He Initialization: אתחול He - אתחול אקראי של משקלים בהתאם למספר הקלטים, מתאים ל-ReLU. מיושם בבנאי הרשת.
40. Argmax: ארגמקס - בחירת המחלקה בעלת ההסתברות הגבוהה ביותר כניבוי הסופי. מיושם בפונקציית הבדיקה.
41. LocalStorage: אחסון מקומי - רכיב HTML5 בדפדפן השומר את משקלי המודל כמחרוזת טקסט ללא פג תוקף.
42. JSON.stringify(): פונקציית JavaScript הממירה את אובייקט המשקלים למחרוזת לצורך שמירה ב-LocalStorage.
43. JSON.parse(): פונקציית JavaScript הממירה את המחרוזת מה-LocalStorage חזרה לאובייקט משקלים.
44. Training Dataset: מאגר אימון - אוסף הצורות המתויגות שעליו לומד המודל (נוצר אוטומטית + דוגמאות שהמשתמש מוסיף).
45. Testing / Prediction: בדיקה / ניבוי - הזנת ציור חדש למודל המאומן וקבלת הסיווג, ללא עדכון משקלים.
